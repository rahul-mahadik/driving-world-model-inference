# Project website

Static source for the DriveBench research website. Serve this directory with any static HTTP server; no build, API keys, cloud account or framework is required.

```sh
python -m http.server 8766 --directory website
```

The site links to the versioned repository evidence and distinguishes measured historical results, CPU software checks and prospective studies. Update claims only alongside reviewed evidence. It contains no hosted evaluation service or leaderboard. Typography optionally loads Google Fonts; system fonts remain available without that request.
